# 디자인 상세 스펙: 컴포즈 앱 내 제휴 이벤트 페이지 구현 및 연동

본 문서는 모카 x 컴포즈커피 제휴 이벤트를 통해 발급받은 커피 수혈 DNA 크레덴셜 정보와 쿠폰 난수 코드를 컴포즈 앱 내부로 연동하여, 사용자가 이벤트 혜택을 확인하고 직접 쿠폰으로 교환할 수 있는 상세 페이지와 쿠폰 등록 로직의 디자인 스펙입니다.

---

## 1. 개요 및 기획 의도
사용자가 모카 웹뷰(Step 3)에서 `[커피 쿠폰 등록하러 가기 →]` 버튼을 누르면 컴포즈커피 앱으로 이동합니다.
단순히 쿠폰 텍스트 코드만 입력하는 기존 레이아웃을 개편하여, 사용자가 참여했던 커피 수혈 DNA 분석 결과(테스트 결과)를 컴포즈 앱 내부의 고유한 브랜드 스타일로 다시 보여줌으로써 제휴 마케팅의 효과를 극대화하고 혜택(무료 아메리카노 교환)을 직관적으로 수령하도록 돕습니다.

---

## 2. 화면 구성 요소 사양

### 2.1 컴포즈 앱 헤더
*   **뒤로가기 버튼 (`#btnComposeBack`)**: 클릭 시 모카 이벤트의 마지막 페이지(Step 3, 인증 완료 및 쿠폰 조회 상태)로 자연스럽게 복귀합니다.
*   **헤더 타이틀**: `제휴 이벤트 상세`

### 2.2 이벤트 안내 배너
*   **비주얼**: 컴포즈 브랜드 정체성을 담은 옐로우(`#FFE300`) 및 블랙 컬러 활용.
*   **텍스트**:
    *   타이틀: `🎁 모카 x 컴포즈커피 제휴 이벤트`
    *   설명: `고객님의 커피 결제 데이터 분석 결과를 기반으로 한 무료 아메리카노 쿠폰 발급 페이지입니다.`

### 2.3 나의 커피 수혈 DNA 결과 카드
*   **목적**: 모카 웹뷰에서 전달받은 `state.segment` 결과 데이터를 컴포즈 앱에 특화된 레이아웃으로 렌더링합니다.
*   **동작**:
    *   `state.segment` 값(Morning, Lunch, Afternoon, Evening)에 매칭되는 유형 타이틀, 등급 명칭, 캐릭터 일러스트를 중앙에 배치합니다.
    *   에너지력, 모임력, 팩폭력, 번개력의 4가지 게이지 바를 시각적으로 노출하며 애니메이션을 실행합니다.
    *   해당 유형의 4가지 특징 설명 텍스트 목록을 보여줍니다.
    *   **카드 컬러 테마**: 각 유형에 따른 그라데이션 컬러 테마(Morning: 오렌지-피치, Lunch: 골드-브라운, Afternoon: 퍼플-바이올렛, Evening: 딥블루-핑크)를 그대로 계승합니다.

### 2.4 쿠폰 교환 및 등록 영역
*   **쿠폰 코드 입력 필드**:
    *   자동 완성: 모카 웹뷰에서 발급된 난수 쿠폰 코드(`state.referralCode`)가 자동으로 채워집니다.
    *   유형 상태에 맞춰 `Read-only`로 활성화되어 오타 없이 등록할 수 있도록 돕습니다.
*   **쿠폰 교환 CTA 버튼 (`#btnComposeRegister`)**:
    *   컴포즈 스타일의 대형 검은색/노란색 버튼으로 `무료 커피 쿠폰 교환하기` 텍스트를 노출합니다.
    *   클릭 시 쿠폰 등록 로직이 실행되고 성공 팝업 모달이 등장합니다.
*   **교환 완료 상태 (`state.isCouponRegistered`)**:
    *   쿠폰 등록이 성공하면 로컬 상태에 `isCouponRegistered: true`가 반영됩니다.
    *   이후 입력 필드는 "교환 완료된 쿠폰 코드" 메시지로 변경되고, 버튼은 `[쿠폰 교환 완료 (등록됨)]`으로 문구가 바뀌며 비활성화(Dimmed) 처리됩니다.

---

## 3. 인터랙션 및 상태 매트릭스

사용자의 진행 상태에 따라 컴포즈 앱 화면은 다음과 같이 동적으로 변경됩니다.

| 상태 단계 | 데이터 조건 | 화면 구성 특징 | CTA 버튼 상태 |
| :--- | :--- | :--- | :--- |
| **미등록 상태 (최초 진입)** | `isCouponRegistered == false` | 자동 완성된 쿠폰 난수 노출, 커피 DNA 상세 정보 렌더링 | **`[무료 커피 쿠폰 교환하기]`** (활성, 검은색 배경) |
| **교환 완료 상태** | `isCouponRegistered == true` | 쿠폰 등록 성공 모달 확인 후, 입력창 잠금 및 안내 표시 | **`[쿠폰 교환 완료 (등록됨)]`** (비활성, 회색 배경) |

---

## 4. 파일 변경 사양

### 4.1 `index.html`
*   컴포즈 앱을 모사하는 컨테이너 내부 구조를 옐로우-블랙 브랜드 테마에 맞추어 개편합니다.
*   기존의 단순 폼 레이아웃을 제거하고, 커피 DNA 결과 카드 렌더링 영역(`#composeResultCard`), 쿠폰 자동 완성 정보 영역, 교환 버튼 영역을 일체형으로 탑재합니다.

### 4.2 `index.css`
*   컴포즈 앱의 결과 카드 및 게이지 바 스타일링을 추가합니다 (`.compose-result-card`, `.compose-stat-bar` 등).
*   컴포즈 브랜드 테마 컬러(`#FFE300`, `#1a1a1a`, `#f5f5f5`)를 활용하여 가독성이 높고 모던한 모바일 카드 스타일을 구현합니다.
*   비활성화된 입력 폼 및 교환 완료 버튼의 스타일링을 추가합니다.

### 4.3 `index.js`
*   `state` 객체에 `isCouponRegistered` 상태 변수를 추가합니다.
*   `renderComposeApp` 함수를 전면 개편하여 옵션 A 레이아웃을 동적으로 빌드하고, 전달받은 `state.segment` 데이터에 맞춰 카드 내부를 상세히 렌더링합니다.
*   `btnComposeRegister` 클릭 시 `isCouponRegistered = true`로 상태를 변경하고, 성공 팝업 모달을 띄운 뒤 확인을 누르면 컴포즈 앱 화면이 "교환 완료" 상태로 리렌더링되도록 구현합니다.
*   시뮬레이터 초기화(`resetSimulator`) 호출 시 `isCouponRegistered = false`도 초기화되도록 보완합니다.
