# 디자인 상세 스펙: 모카 x 컴포즈커피 통합형 동적 이벤트 페이지 개편

본 문서는 OK캐쉬백 커피 결제 데이터를 활용한 블록체인 크레덴셜 발급 및 검증 이벤트를 단일 뷰포트 내의 통합 동적 레이아웃으로 개편하기 위한 프론트엔드 디자인 스펙입니다.

---

## 1. 개요 및 기획 의도
기존의 3단계 스텝 카드 레이아웃은 화면 스크롤이 길고 진행 단계에 따른 상태 변화가 유기적으로 보이지 않았습니다. 
이를 해결하기 위해 **단일 통합형 동적 이벤트 카드(Unified Dynamic Card)** 레이아웃으로 전면 개편합니다.

사용자는 하나의 메인 히어로 카드와 CTA 버튼 영역만 응시하면서, **[데이터 분석/발급] → [시간대 크레덴셜 획득] → [인증/검증] → [쿠폰/포인트 보상 획득 및 컴포즈 앱 연결]**까지의 전체 흐름을 매끄러운 트랜지션 애니메이션과 함께 직관적으로 인지할 수 있습니다.

---

## 2. 화면 구성 요소 사양

### 2.1 이벤트 타이틀 및 서브 타이틀
*   **위치**: 이벤트 페이지 상단 배너 영역 (`.moca-banner`)
*   **타이틀**: `내 커피 수혈 타임은 언제? ☕️`
*   **서브 타이틀**: `결제 데이터를 기반으로 나의 수혈 타임을 진단하고 3,000P 적립과 무료 커피 쿠폰을 받아보세요!`

### 2.2 롤링 텍스트 배너 (`#mocaRollingTicker`)
*   **목적**: 사용자가 자신의 수혈 유형을 진단하기 전, 흥미를 돋우기 위해 4가지 시간대 유형의 멘트가 끊임없이 부드럽게 순환 노출되는 텍스트 영역입니다.
*   **동작**:
    *   2.5초 간격으로 다음 멘트가 Fade In/Out 및 위로 슬라이딩되며 전환됩니다.
    *   *멘트 리스트*:
        1.  `🌅 오전 08:00 | 출근길 눈번쩍 생명수 수혈 타임`
        2.  `☀️ 오후 13:00 | 식후 졸음방지 아메리카노 필수 타임`
        3.  `⚡️ 오후 15:30 | 나른함 타파를 위한 샷 추가 타임`
        4.  `🌙 저녁 18:30 | 퇴근길 하루를 보상하는 힐링 충전 타임`
*   **노출 여부**: 최초 진입 시 활성화되며, **크레덴셜 발급 완료 이후에는 화면에서 숨김(d-none 또는 fade-out) 처리**됩니다.

### 2.3 통합형 히어로 카드 영역 (`#mocaHeroContainer`)
*   사용자의 상태에 따라 아래의 3가지 모습으로 동적 렌더링되는 핵심 영역입니다.

#### **상태 A: 최초 진입 (미발급 상태)**
*   **비주얼**: 어두운 빈 카드 외곽선, 맥박 소리처럼 서서히 깜빡이는 펄스(Pulse) 광원 효과.
*   **중앙 아이콘**: 잠금 자물쇠 아이콘 (`🔒`) 또는 보안 칩 실루엣.
*   **텍스트**: "나의 커피 결제 이력을 분석해 주세요."

#### **상태 B: 크레덴셜 발급 완료 (인증 대기 상태)**
*   **비주얼**: 무작위(Random)로 매칭된 4대 세그먼트 중 하나의 대형 크레덴셜 카드 렌더링.
*   **세그먼트 매칭 리스트**:
    1.  **Morning (아침)**: `"출근길 눈번쩍 생명수 수혈러"`
        *   비주얼 테마: 오렌지-피치 네온 그라데이션 (`linear-gradient(135deg, #FF9966, #FF5E62)`) + `🌅` 아이콘
    2.  **Lunch (점심)**: `"식후 아메리카노 필수러"`
        *   비주얼 테마: 골드-브라운 웜 그라데이션 (`linear-gradient(135deg, #8D6E63, #4E342E)`) + `☕️` 아이콘
    3.  **Afternoon (오후)**: `"나른함 타파 샷추가러"`
        *   비주얼 테마: 퍼플-일렉트릭 바이올렛 그라데이션 (`linear-gradient(135deg, #7F00FF, #E100FF)`) + `⚡️` 아이콘
    4.  **Evening (저녁)**: `"퇴근길 힐링 충전러"`
        *   비주얼 테마: 딥블루-선셋 핑크 그라데이션 (`linear-gradient(135deg, #111827, #ec4899)`) + `🌙` 아이콘
*   **카드 정보**: 크레덴셜 명칭 (`CoffeeTimeCredential`), 안전 증명 마크 및 암호화 그래픽.

#### **상태 C: 크레덴셜 인증 완료 (보상 지급 상태)**
*   **비주얼**: 발급된 크레덴셜 카드 우측 상단에 청록색 **[인증 완료 (Verified) ✓]** 스탬프/배지 노출.
*   **추가 컴포넌트**: 카드 하단에 **컴포즈 커피 무료 쿠폰 티켓** 비주얼이 슬라이드업 애니메이션으로 등장.
    *   *티켓 스타일*: 화이트/크림 톤의 쿠폰 티켓 형태, 양 옆 원형 펀칭 컷아웃, 쿠폰명("아메리카노 1잔 무료 교환권"), 랜덤 생성된 바코드 이미지 및 텍스트 코드.

## 3. 인터랙션 및 버튼 상태 매트릭스

사용자의 동작에 따라 메인 버튼과 하단 링크가 유기적으로 활성화 및 변경됩니다.

| 상태 단계 | 사용자 액션 및 프로세스 | 통합 CTA 버튼 상태 | 하단 쿠폰 링크 노출 여부 |
| :--- | :--- | :--- | :--- |
| **0. 최초 상태** | 최초 진입 (미발급) | **`[내 커피 수혈 타임 알아보기]`** (활성) | 미노출 |
| **1. 발급 중** | 버튼 클릭 → Air SDK 바텀시트 분석 | **`[데이터 분석 중...]`** (로딩/비활성) | 미노출 |
| **2. 발급 완료** | Air SDK 닫힘 → 랜덤 세그먼트 배정 | **`[내 커피 수혈 타임 인증하기]`** (활성) | 미노출 |
| **3. 인증 중** | 버튼 클릭 → 레이저 스캔 애니메이션 (1.2초) | **`[크레덴셜 검증 중...]`** (로딩/비활성) | 미노출 |
| **4. 인증 완료** | 검증 완료 → OCB 3,000P 토스트 및 쿠폰 생성 | **`[인증 완료 (3,000P 지급됨)]`** (비활성) | **`[커피 쿠폰 등록하러 가기 →]`** 노출 |

## 4. 상세 파일 구조 변경안

### 4.1 `index.html` 변경 사항
*   `.moca-steps-area` 영역 전체를 삭제합니다.
*   대신 단일 컨테이너인 `#mocaUnifiedCard` 구조를 주입합니다.
    ```html
    <div class="moca-unified-card" id="mocaUnifiedCard">
      <!-- 롤링 멘트 텍스트 -->
      <div class="moca-rolling-ticker" id="mocaRollingTicker">
        <span class="ticker-text" id="tickerText">🌅 오전 08:00 | 출근길 눈번쩍 생명수 수혈 타임</span>
      </div>

      <!-- 히어로 크레덴셜 카드 컨테이너 -->
      <div class="hero-credential-container" id="heroCredContainer">
        <!-- 레이저 스캔라인 -->
        <div class="laser-line" id="laserLine"></div>
        <!-- 내부 동적 카드 렌더링 영역 -->
        <div id="mocaCardRender"></div>
      </div>

      <!-- 리워드(쿠폰) 영역 (인증 완료 시 슬라이드 노출) -->
      <div class="moca-reward-area" id="mocaRewardArea"></div>

      <!-- 통합 CTA 버튼 -->
      <button class="moca-btn moca-btn-primary" id="btnMocaCTA">내 커피 수혈 타임 알아보기</button>

      <!-- 앱 이동용 2차 CTA 버튼 (인증 완료 시 노출) -->
      <div class="moca-link-button-area" id="mocaLinkArea"></div>
    </div>
    ```

### 4.2 `index.css` 변경 사항
*   기존 step 카드 CSS 스타일 삭제.
*   `.moca-rolling-ticker` 페이드 트랜지션 스타일링.
*   크레덴셜 카드 세그먼트별 그라데이션 및 쉐도우 효과 정의.
*   인증 완료 상태 시 나타날 쿠폰 티켓 비주얼 클래스(`.moca-ticket`, 점선 보더, 바코드 스타일링 등) 추가.
*   레이저 스캔 라인의 동적 애니메이션 정의.

### 4.3 `index.js` 변경 사항
*   `state` 객체의 `segment` 기본값을 `null` 또는 미지정으로 변경.
*   `Math.random()`을 사용하여 4가지 중 하나의 세그먼트를 무작위로 선택하는 헬퍼 함수 구현:
    ```javascript
    const segments = ["Morning", "Lunch", "Afternoon", "Evening"];
    state.segment = segments[Math.floor(Math.random() * segments.length)];
    ```
*   롤링 텍스트를 제어하는 `setInterval` 타이머 정의 (발급 완료 시 소멸 처리).
*   `renderMocaEventPage` 함수가 단일 통합 레이아웃 `#mocaUnifiedCard` 내부를 각 단계(`currentStep`)에 부합하게 직접 렌더링하고 상태별 바인딩을 수행하도록 최적화.
