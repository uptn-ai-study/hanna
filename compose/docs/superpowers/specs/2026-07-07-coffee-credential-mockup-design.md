# 디자인 명세서: 블록체인 크레덴셜 기반 커피 소비 데이터 마케팅 이벤트 모의 웹앱 (Mock-up)

본 문서는 OK캐쉬백 및 모카 네트워크의 커피 크레덴셜 발급/검증 이벤트 기획안(`COFFEE_CREDENTIAL_PROPOSAL.md`)에 맞춘 대화형 모바일 시뮬레이터 웹앱의 디자인 명세서입니다.

---

## 1. 개요 및 설계 목적
* **목적**: 기획자, 개발자 및 비즈니스 제휴 파트너(컴포즈커피)가 연동 흐름을 직관적으로 검증할 수 있는 모바일 형태의 대화형 Mock-up을 제공합니다.
* **대상 흐름**:
  1. 대상자 체크 (Step 0)
  2. Air SDK를 통한 커피 시간대 크레덴셜(`CoffeeTimeCredential`) 발급 (Step 1)
  3. 모카 네트워크 내 크레덴셜 검증 및 OCB 700P 지급 (Step 2)
  4. 컴포즈 앱으로 딥링크 연동 및 레퍼럴 코드 자동 완성을 통한 1,800원 쿠폰 획득 (Step 3)

---

## 2. 디자인 시스템 및 테마 정의

시뮬레이터 내부 화면은 단계별 상황에 맞는 브랜드 정체성을 유지하여 몰입감을 높입니다.

| 화면 구분 | 브랜드 테마 | 주요 색상 코드 (HEX) | 디자인 특징 |
| :--- | :--- | :--- | :--- |
| **모카 네트워크 (Event)** | 모카 브라운 & 라이트 그레이 | `#2F2E2C` (Warm Charcoal), `#D4A373` (Mocha), `#F8F9FA` (Background) | 정돈되고 신뢰감 있는 마케팅 카드 UI, 부드러운 브라운 톤 강조 |
| **Air SDK (Wallet)** | 다크 테크 (Web3) | `#0E0E10` (Dark Dark), `#00F0FF` (Neon Cyan), `#FFFFFF` (Card Text) | 검정 배경의 사이버네틱 무드, 고대비 네온 포인트 컬러, 디지털 크레덴셜 증명서 그래픽 |
| **컴포즈 커피 (Compose)** | 옐로우 & 블랙 | `#FFE300` (Compose Yellow), `#1A1A1A` (Compose Dark) | 시그니처 컬러를 활용한 산뜻하고 직관적인 프랜차이즈 앱 UI |

---

## 3. 화면별 구성 및 세부 스펙

### 3.1 디바이스 프레임 (스마트폰 목업)
* **데스크톱 화면**: 화면 중앙에 아이폰 15 Pro 스타일의 다크 베젤 프레임 배치.
* **상태 바(Status Bar)**: 상단에 시계, 셀룰러 아이콘, 와이파이, 배터리 잔량 표시.
* **액션 및 페이지 전환**: 슬라이드 및 페이드 인/아웃 트랜지션으로 네이티브 앱 같은 조작감 부여.

### 3.2 화면 1: 모카 이벤트 페이지 (최초 진입)
* **배너 영역**:
  * 타이틀: `커피로 나의 유형 알아보고 700P + 컴포즈 커피 할인 쿠폰 받기!`
  * 서브 타이틀: `내가 주로 커피를 구매하는 시간대를 확인하고 블록체인 크레덴셜을 발급받아 보세요. 인증 완료 시 OK캐쉬백 700P 적립과 함께 컴포즈 커피 쿠폰(1,800원 상당) 혜택을 드립니다.`
  * 기간: `2026. 09. 01 ~ 2026. 09. 30`
* **3단계 스텝형 카드 레이아웃**:
  * **Step 1 카드**: `[커피 구매 시간대 크레덴셜 만들기]` 버튼 제공. 카드 내 크레덴셜 그래픽은 발급 전까지 흐릿한 블러(blur) 효과 및 잠금 아이콘 표시.
  * **Step 2 카드**: `[인증하고 혜택 받기 (700P)]` 버튼 제공. 비활성화(Dimmed, 투명도 50%, 클릭 불가) 처리.
  * **Step 3 카드**: `[컴포즈 커피 쿠폰 받으러 가기]` 버튼 제공. 비활성화(Dimmed, 투명도 50%, 클릭 불가) 처리.

### 3.3 화면 2: Air SDK 바텀시트
* **진입 연동**: Step 1 버튼 클릭 시 하단에서 부드럽게 슬라이드 업(`transform: translateY(0)`)되며 모달 백드롭 활성화.
* **본문 정보**:
  * 상단 로고: `AIR`
  * 안내 문구: `Store your information securely`
  * 연동 계정: OCB 포인트 보유 등급 `100,000 P` 및 모카 체인 연결 상태 표시.
* **인터랙션**:
  * `Confirm` 버튼 클릭 시, "데이터 조회 중...", "크레덴셜 생성 중..." 애니메이션 스피너가 표시되고 1.5초 후 완료 처리.
  * 완료 시 바텀시트가 닫히며 모카 이벤트 웹뷰 화면으로 복귀.
  * **상태 변화**: Step 1 카드의 블러가 해제되고 활성화 상태로 전환. 발급된 크레덴셜 정보로 **'점심형 (Lunch: 10:00 ~ 14:00)'** 텍스트와 디지털 인증서 그래픽이 선명하게 노출됨. Step 2 카드 활성화.

### 3.4 화면 3: 크레덴셜 검증 및 700P 지급
* **진입 연동**: Step 2 카드의 `인증하고 혜택 받기` 버튼 클릭 가능.
* **인터랙션**:
  * 버튼 클릭 시 크레덴셜 카드 위로 레이저 라인이 위아래로 움직이는 스캔 애니메이션 발생 (1초간).
  * 검증 성공 토스트: "OK캐쉬백 700P가 지갑으로 즉시 지급되었습니다!" 알림 노출.
  * **상태 변화**: Step 2 카드가 '완료(Dimmed)' 상태로 바뀌고, 화면에 고유 레퍼럴 코드 `COMP_LUNCH_W3B9X7`가 텍스트 형태로 로드됨. Step 3 카드 활성화.

### 3.5 화면 4: 컴포즈 커피 앱 랜딩 (Approach B)
* **진입 연동**: Step 3 카드의 `컴포즈 커피 쿠폰 받으러 가기` 버튼 클릭 시 동작.
* **인터랙션**:
  * 스마트폰 프레임 내부 화면이 모카 웹뷰에서 '컴포즈 커피' 앱 실행 모션(스플래시 화면 0.8초 노출 후 쿠폰 페이지로 랜딩)으로 전환됨.
  * **자동 완성(Auto-fill)**: 쿠폰 코드 입력 필드에 `COMP_LUNCH_W3B9X7`가 이미 채워져 있고 수정 불가능(Read-only) 형태로 배치되어 편의성 체감.
  * `등록` 버튼 클릭 시, 등록 완료 모달 팝업 노출: "쿠폰 등록 성공! 컴포즈 아메리카노 1잔 무료 쿠폰(1,800원 상당)이 발급되었습니다. 컴포즈 앱의 [마이 쿠폰함]에서 확인하세요."

## 4. 예외 케이스 테스트 시뮬레이션 지원 (추가 설계)
사용자가 시뮬레이션을 반복하거나 다양한 각도에서 테스트할 수 있도록 화면 하단 또는 외곽에 **[시뮬레이션 조작 패널]**을 작게 구성하여 다음을 제공합니다.
* **흐름 초기화 (Reset)**: 클릭 시 모든 상태를 최초 이벤트 진입 상태(Step 0)로 되돌림.

---

## 5. 검증 계획
* **인터랙션 정확도**: 스텝별 버튼 제어 매트릭스(Dimmed -> Active)가 기획서의 상태 전이 규칙과 정확히 일치하는지 검증.
* **자동 완성 기능**: Step 3 진입 시 Step 2에서 생성된 동일한 레퍼럴 코드가 컴포즈 쿠폰 필드에 오차 없이 자동 기입되는지 검증.
* **모바일 뷰 적합성**: 데스크톱 크롬 브라우저와 모바일 모드 모두에서 깨짐 없이 스마트폰 시뮬레이터가 미려하게 동작하는지 검증.
